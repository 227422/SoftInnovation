# 「知要」产品现状说明（2026-11-17）

## 这是什么

「知要」是一个给本科生用的校园通知助手。

学校官网、学院、教务、团委等地方每天都在发通知，但学生真正关心的是：**这件事和我有关吗？什么时候截止？参加有什么收益？要满足什么条件？** 现在这些信息散落在不同网页里，标题还经常看不出重点。

「知要」想做的事是：把校内的通知收集起来，按「科研、竞赛与创新」「奖助与学生权益」「日常通知」三类整理，并直接告诉你每条通知的**关键日期、可能的收益类型、面向哪些人、文件处于什么状态**，点开还能看正文、附件和政策依据。

它不替你报名，也不替你做决定；它帮你更快看清楚，再自己判断。

---

## 现在打开 App 能看到什么

打开后默认是「**样例数据**」模式，里面是一套**专门做出来的演示内容**（虚构学校、虚构通知、虚构政策），用来完整走一遍产品流程：

1. 用任意合法邮箱 + 8 位以上密码登录（样例模式不连真实服务器）；
2. 选择学校 / 学院 / 专业 / 年级，可填入学年份、确认本科身份，也可以先跳过；
3. 在「偏好设置」里选课程、技能、目标、兴趣（全部可选，不选也不影响使用）；
4. 首页三个 Tab 看通知列表：每条标题右侧先给最要紧的一个日期和收益类型，下面一行再列其余日期、面向群体、是否公示/已结束等标签，同一信息不会重复出现；
5. 点标题进详情：顶部一次列出全部日期、收益、面向群体和文件状态，紧接着就是正文；来源链接、附件、政策依据和数据版本收在折叠区，需要时再点开；
6. 点「关注」把通知收藏，在「我的 → 我的关注」里按关注时间查看、取消关注；
7. 「我的」里可以看自己的身份资料、修改资料、切换环境、退出登录。

想快速验收产品方向，直接看样例数据就够：8 条通知覆盖了"四档收益排序""收益待确认""仅标题""正文有更新""期限未注明""时间待确认""结果公示"等关键情况。

## 哪些是真的，哪些是演示

| 部分 | 现在的状态 | 说明 |
|---|---|---|
| 注册、登录、会话保持、退出 | **真实可用**（连后端时） | 邮箱密码注册登录，会话 30 天；退出只清本机会话 |
| 身份资料（学校/学院/专业/年级/入学年份/本科身份） | **真实可用**（连后端时） | 保存在账号下，重开、重登、换设备可读回 |
| 可选偏好（课程/技能/目标/兴趣） | **真实可用**（连后端时） | 独立保存，失败不影响资料和浏览 |
| 学校/学院/专业/年级目录 | **真实可用**（连后端时） | 都是中南大学的真实目录数据 |
| 专业大类（按当届招生/分流规则） | **真实接口，但目前显示"待确认"** | 后端暂时无法唯一确认归属，按约定不猜测，显示"待确认" |
| 课程目录 | **真实接口，但目前为空并提示待核验** | 后端未核实课程前不编造选项，可跳过 |
| 三类通知列表、详情、我的关注 | **演示（合成样例）** | 后端的这三个接口还没实现（计划 S3/S4）。界面、数据格式和流程都已完成；等后端上线后接真实数据 |
| 关注（收藏、取消、时间倒序） | **演示（合成样例）** | 同上，关注功能依赖 S4 接口 |
| 截止提醒、AI 解读、搜索、分享、忽略 | **尚未做** | 这些是后续版本规划，首版刻意不做 |
| 公网访问、正式域名、应用商店发布 | **尚未做** | 后端目前只能在本机运行；跨网 HTTPS 是后续阶段 |

一句话：**账号和身份资料这条链路是真的；通知内容目前还是演示数据。**

## 怎么试用

**只看界面和流程（不需要电脑）**：安装 `app-debug.apk`，默认就是样例数据模式，用任意邮箱 + 8 位以上密码登录即可走完全流程。

**连真实后端试用（需要两个人配合/一台电脑）**：
1. 电脑上启动后端服务（后端同学提供命令）；
2. 手机用 USB 连接电脑并开启调试，执行一条端口转发命令；
3. App 内「我的 → 开发环境切换 → 本机后端」，确认后重新登录；
4. 这时注册、登录、资料、偏好是真实保存到后端的；通知列表会明确提示"接口尚未上线"（正确行为，不是故障）。

**正式服务**：后端部署 HTTPS 网址后，填写地址即可切换；目前还没有可用地址。

## 当前限制（如实说明）

- 通知列表/详情/关注没有真实数据，只有演示样例；不要把这个阶段的演示内容当成真实通知。
- 已在真机 **vivo V2408A（Android 16）** 上完成两轮设备验收：第一轮（11-19）真实注册/登录、资料保存与重读、入学年份清除、偏好保存、断网保留草稿并重试成功、退出与重登、三 Tab 切换通过；第二轮（11-20）验证了多设备同时修改资料时的冲突提示（自动重读服务端值后可再次保存成功），并在电脑侧复核了版本冲突、幂等重放、30 天会话不因刷新续期、会话失效返回 401 等行为。两设备同时在线、会话到期实机、换账号隔离、跨网 HTTPS 仍未验证（详见会话目录 `device-acceptance\DEVICE-ACCEPTANCE-2026-11-19.md`）。
- 后端只能在本机运行，还没做公网/HTTPS；两个人异地试用还需要额外的网络方案。
- 专业大类、课程目录、政策依据的覆盖率取决于后端的核验进度；没把握的地方一律显示"待确认"，不猜。
- 未做：提醒/通知推送、AI 总结、搜索筛选、多学校、微信/QQ 登录、找回密码。

---

## 数据与隐私（简单说）

- 密码不会以明文保存；会话用 Cookie 记录，退出即清本机凭据。
- 资料只用于判断通知是否与你相关；不同账号的资料、关注和缓存互相隔离。
- 演示模式（样例数据）不联网、不写任何服务器。
- 目前没有采集用户行为做推荐，没有第三方账号绑定。
