## 第二轮（2026-11-20，电脑侧复核 + A06 应用端）

环境：后端仍为同一克隆 `f47efe9`，本机 `http://127.0.0.1:8000`；手机 V2408A 经 `adb reverse` 连 LOCAL。脚本与原文：`http\`（`backend-http-checks.ps1`、`summary.txt`、每步 `*.headers.txt` / `*.body.json`）。

| 复核项 | 结果 |
|---|---|
| A06 版本冲突 | 旧 `expected_version` 提交 → `409 version_conflict`（a06-stale-save） |
| A07 幂等 | 同 key + 同 body 重放 → 200 且响应体完全相同；同 key + 不同 body → `409 key_payload_conflict`（a07-idem-*） |
| A10 不续期 | `POST /v1/auth/refresh` 前后 `expires_at` 不变；`GET /v1/auth/session` 同值（a10-*） |
| A10 过期/失效 | 把 `auth_sessions.expires_at` 改为过去 → 鉴权请求 `401 session_invalid`；删除会话行 → 同样 401（a10-expired-session / a10-deleted-session） |
| A11 request_id | 未登录等“早退”错误同样带 `X-Request-ID`，与正文 `request_id` 一致（a11-bogus-cookie） |
| v2 planned 路径 | `/v2/me/notices`、`/v2/me/follows`、`/v2/coverage`、`/v2/me/notices/{id}/follow` 全部 `404 request_rejected`（v2-*） |

A06 应用端：编辑页载入 version 3 → 电脑会话保存成 version 4 → App 保存 → 提示“资料已被其他设备更新，已重新读取，请确认后再保存”，年级显示服务端值 → 再次保存成功（HTTP 读回 version 5）。截图 s47（载入）、s48（冲突提示）、s49（重存成功回首页）。**注意**：App 的做法是重读并覆盖本地草稿，与清单原文“保留草稿并重读”不完全一致，已如实记录。
